# File Organization Audit Criteria

## Components
- Components in `components/[feature]/[componentName]/ComponentName.tsx`?
- Each component lives in its own folder named in camelCase matching the component name?

## Pages
- Pages in `app/[route]/page.tsx`?

## Server Actions
- Server Actions in `actions/[feature].ts`?

## Types
- Types in `types/db.ts` (single file for all Zod schemas)?

## Lib/Utils
- Lib/utils in `lib/[utility].ts`?
