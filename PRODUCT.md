# Product

## Register

product

## Users

Everyday developers who keep their knowledge scattered across VS Code, Notion, GitHub Gists, browser bookmarks, and chat histories. They need one fast, searchable hub to collect, organize, and retrieve code snippets, AI prompts, commands, links, and notes.

## Product Purpose

DevStash is a unified developer knowledge hub. It lets users collect items (snippets, prompts, commands, notes, files, images, links) into collections, search across everything, and retrieve context when they need it. Pro tier adds file uploads, AI auto-tagging, code explanation, and prompt optimization.

## Brand Personality

Sleek, fast, professional. A tool that respects developers' time — no fluff, no gimmicks. Clean interface that feels like it belongs alongside Linear, Raycast, and Notion.

## Anti-references

No neon cyberpunk aesthetics. Avoid saturated neon colors, dark-mode glow effects, or anything that reads as a gaming/entertainment interface rather than a developer tool.

## Design Principles

1. **Speed-first interface** — Every interaction should feel instant. Minimal loading, fast transitions, immediate feedback.
2. **Context over decoration** — Every pixel serves a purpose. No decorative elements that don't aid discovery or retrieval.
3. **Dark mode by default** — Developers work in dark environments. The interface should feel native to that context.
4. **Type-driven organization** — Item types are the primary mental model. Visual distinction between types matters more than everything else.
5. **Progressive disclosure** — Show what's needed now, reveal detail on demand. Keep the dashboard clean; complexity lives in item views.
